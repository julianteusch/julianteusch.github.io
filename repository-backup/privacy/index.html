Repository Backup

Privacy Policy

Effective date: September 2, 2026

Purpose and operator

Repository Backup is a personal, non-commercial utility operated solely by Julian Teusch. It is used to store encrypted backups in a Google Drive account controlled by the operator. It is not made available to other users.

Google user data

The utility requests Google Drive access so it can create backup folders, upload encrypted repository archives and checksums, read uploaded archives for integrity verification, apply the configured retention policy, and restore backups at the operator's request.

Processing and storage

Repository data is processed locally on the operator's device. Backup contents and filenames are encrypted before they are uploaded. The resulting encrypted files are stored only in the operator's Google Drive account. OAuth credentials are stored locally on the operator's device and are not transmitted to an application server.

Sharing and advertising

No Google user data is sold, shared with third parties, used for advertising, or used to train machine-learning models. The utility has no analytics, tracking, or external application backend.

Retention and deletion

Backups are retained according to the operator's configured daily, weekly, and monthly retention policy. The operator can delete backup data directly from Google Drive at any time. Google access can be revoked from the security settings of the operator's Google Account.
