Repository Backup

Repository Backup is a private command-line utility operated by Julian Teusch. It creates verified archives of repositories that Julian is authorized to access and stores encrypted backup files in Julian's own Google Drive account.

The utility is not offered to the public, does not provide accounts for other users, and does not run an external application server. Google Drive access is used only to create, verify, retain, and restore the backup files requested by the account owner.
